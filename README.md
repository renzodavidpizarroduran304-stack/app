# ADMIN

Aplicación Android nativa para registrar y controlar deudas, cuotas y comprobantes de pago.

> **Rama de trabajo:** `admin-app`  
> **Estado:** en desarrollo. La compilación local se ha realizado correctamente, pero todavía falta completar las pruebas de ejecución y verificar todas las funciones en el emulador.

## Cómo continuar este proyecto en un chat nuevo

1. Comparte el enlace de este repositorio y especifica la rama `admin-app`.
2. Pide revisar primero `docs/PROJECT_CONTEXT.md`, `docs/REQUIREMENTS_ADMIN.md` y `docs/TECHNICAL_STATUS.md`.
3. Antes de modificar código, compara la documentación con el código real de la rama.
4. Actualiza la documentación cuando cambien requisitos, arquitectura, estado o comportamiento.
5. Registra cada cambio importante en `CHANGELOG.md`.

No dependas del historial de una conversación para conocer el proyecto: la fuente de verdad es el código y la documentación de esta rama.
